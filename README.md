# 📊 Real-Time Stock Market Dashboard

🚀 **Live App:** https://stockdashboardlive.streamlit.app/

---

## ✨ Overview

A **real-time, interactive stock market dashboard** built with **Python + Streamlit**.
Track live prices, analyze trends, and compare multiple stocks with a sleek **glassmorphism + neon UI**.

---

## 🔥 Features

* 📈 **Live Stock Data** (via Yahoo Finance API)
* 🕯 **Candlestick & Line Charts**
* 📊 **Technical Indicators** (Moving Average)
* 🔍 **Multi-Stock Comparison**
* ⚡ **Auto Refresh (Real-Time Updates)**
* 🌙 **Dark / Light Mode Toggle**
* 💎 **Modern UI** (Glassmorphism + Neon Design)
* 🛑 **Error Handling for invalid inputs**

---

## 🖼️ Preview

> Live demo: https://stockdashboardlive.streamlit.app/

## 🛠️ Tech Stack

* **Frontend/UI:** Streamlit
* **Data Processing:** Pandas
* **Data Source:** yFinance API
* **Visualization:** Plotly

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/stock-dashboard.git
cd stock-dashboard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```

## ⚙️ Usage

1. Enter a **stock symbol** (e.g., AAPL, TSLA, META)
2. Select **time interval & period**
3. Choose chart type (**Line / Candlestick**)
4. Compare multiple stocks
5. Enable auto-refresh for live tracking
